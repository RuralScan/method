# Rural Scan dashboard

[Open the dashboard](https://ruralscan.github.io/method/).

This branch publishes the existing static evidence dashboard on GitHub Pages. The interface and its data references are pinned to [CIAT release `bec50bc0f9dc`](https://github.com/CIAT/nbs_ruralscan/tree/bec50bc0f9dc74b3d5ffafcf881571a8a8ec5c06/docs). The JSON data and available source images load directly from that immutable revision. Live review runs in the CIAT checkout.

GitHub Pages serves the root of the `gh-pages` branch. The methodology and cookbook are maintained on `main`.
